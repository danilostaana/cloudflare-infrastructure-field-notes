# Contributing

Contributions that improve clarity, correctness, safety, or portability are welcome.

## Before submitting

- use sanitized examples;
- do not include real credentials;
- do not include customer data;
- avoid screenshots containing account identifiers unless necessary and intentionally redacted;
- prefer official Cloudflare documentation when making factual claims about Cloudflare behavior;
- distinguish personal operational preference from Cloudflare requirements.

## Style

Write like operational documentation:

- explain the reason for a step;
- state assumptions;
- avoid exaggerated security claims;
- avoid marketing language;
- prefer reproducible procedures.



## Contributions and rights

This repository does not currently use an open-source or Creative Commons license.

If you submit a contribution, only submit material that you created yourself or that you have the right to contribute. Do not submit proprietary client material, confidential employer information, copied articles, copied vendor documentation, or other material that you do not have permission to publish.

By submitting a pull request, you are asking for your contribution to be incorporated into this public repository. Do not submit anything that you are not comfortable having publicly visible through GitHub.

If a contribution introduces substantial original material or raises a licensing question, it may be discussed before merge.
