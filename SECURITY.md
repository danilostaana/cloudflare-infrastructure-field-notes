# Security Policy

## Purpose

This repository contains public documentation and sanitized examples.

Do not submit real credentials, customer information, private infrastructure data, or security-sensitive production details in issues, pull requests, discussions, screenshots, or example files.

## If you find a secret

If you discover what appears to be a real credential in this repository:

1. Do not test or use it.
2. Do not repost it in an issue, discussion, pull request, or public comment.
3. If the credential belongs to you, revoke or rotate it immediately.
4. If it appears to belong to this project or another person, use an available private reporting/contact channel instead of reproducing the value publicly.
5. Treat the credential as potentially compromised until the owner confirms it has been revoked or rotated.

## What not to report publicly

Do not publicly post:

- live API tokens or keys;
- passwords;
- session cookies;
- private keys;
- recovery codes;
- customer data;
- sensitive production topology;
- exploit details for an unpatched private system.

## No security guarantee

The material here is operational documentation and educational reference material. It does not guarantee that a deployment is secure, compliant, or suitable for a specific environment.

Cloudflare and GitHub behavior can change. Platform-specific claims should be checked against the current official documentation before production use.
